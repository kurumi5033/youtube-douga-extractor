YouTube APIキーの取り方

写真つき・やさしいことばで説明します。ゆっくり順番にやれば大丈夫です。

🤔 そもそも「APIキー」ってなに？

このツールが YouTube に「動画をさがして！」とお願いするとき、 「これは私です」と証明するための、特別なパスワードが必要です。 それが「APIキー」です。おうちの鍵や、図書館の利用カードのようなものだと思ってください。 Googleのサイトで、無料でもらうことができます。

📍 ぜんぶで4つのステップです

🔐
① ログイン
📁
② プロジェクト作成
📺
③ YouTube機能をON
🔑
④ キーをコピー
1

Google Cloud Console を開いて、ログインする

まず下のリンクを開きます。いつも使っているGoogleアカウント（GmailなどのID）でログインしてください。

Google Cloud Console を開く ↗
2

「プロジェクト」を新しく作る

画面の上のほうにある「プロジェクトを選択」というところをクリックし、 「新しいプロジェクト」を選びます。名前はなんでもOKです（例:「youtube-extractor」）。

console.cloud.google.com
上のバーのイメージ図
📁 プロジェクトを選択 ▾
↓クリックすると出てくる
＋ 新しいプロジェクト

※ 実際の画面とは少し違いますが、だいたいこんな感じの場所にあります。

3

「YouTube Data API v3」を探して、ONにする

左がわのメニューから「APIとサービス」→「ライブラリ」を選びます。 検索ボックスに「YouTube Data API v3」と入力して、出てきたものをクリックし、 「有効にする」ボタンを押します。

console.cloud.google.com
📚 ライブラリ
🔑 認証情報
🔍 YouTube Data API v3
✅ 有効にする
4

「認証情報」から、キーを作る

左のメニューの「認証情報」をクリックし、上のほうにある 「認証情報を作成」→「APIキー」を選びます。

console.cloud.google.com
📚 ライブラリ
🔑 認証情報
＋ 認証情報を作成 ▾
APIキー
5

出てきた文字（キー）を、コピーする

「AIzaSy…」から始まる、長い英数字の文字が表示されます。これがAPIキーです。 右がわのコピーのボタンを押して、コピーしておきましょう。

APIキーを作成しました
AIzaSyD8x•••••••••••••••••• 📋 コピー
⚠️ だいじな注意: このキーは、あなたのおうちの鍵と同じくらい大切なものです。 友だちや、知らない人に見せたり、SNSに貼ったりしないでください。 このツールでは、あとで「Google Apps Script」という裏側の場所にだけ保存するので、 ホームページの入力欄には入れません。
6

（おすすめ）キーに「制限」をかけておく

キーの右がわにある鉛筆マーク（編集）を押すと「制限」の設定ができます。 「APIの制限」で YouTube Data API v3 だけを選んでおくと、 もしキーが漏れてしまっても、YouTube検索以外には使われないようにできます。 自転車のカギを、その自転車専用にするようなイメージです。

7

1日に使える回数には、上限があります

このキーは無料ですが、1日に検索できる回数に上限があります （1日ぶんの検索チケットが10,000枚、1回の検索で100枚使うイメージです）。 使いきってしまっても、次の日になればまた使えるようになります。

🎉

これでAPIキーの取得は完了です！

コピーしたキーは、README の「2. Google Apps Script でバックエンドを作る」の手順で使います。
